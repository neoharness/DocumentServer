# Supplemental font source

The pinned `core-fonts` submodule contains Liberation Fonts 1.07.4 binaries but
does not contain their preferred source form or license text. neoHarness adds
the unmodified upstream source release to the corresponding-source tree:

- File: `upstream-sources/liberation-fonts-1.07.4.tar.gz`
- Upstream: `https://releases.pagure.org/liberation-fonts/liberation-fonts-1.07.4.tar.gz`
- SHA-256: `ad98b7498dc2992f7f0868f79b65ce4a720a3acdb63ab3f1f1cb6881117a5406`
- Embedded binary version: `1.07.4`

The archive includes the SFD sources, build scripts, Liberation Fonts license,
and GNU GPL version 2 text. The archive is retained byte-for-byte; it is not a
neoHarness fork or engine patch.
